# 盈利回吐保护改造方案 v4（90 分门槛修订稿）

日期：2026-10-29。状态：方案评审阶段，未修改代码、配置、GitHub 或 VPS。

基线：v3 评分 88/100。v4 只修订 v3 的否决项和可执行性缺口，不把 v3 的评分自动带入 v4。

## 1. 明确删除的高风险动作

v4 **删除 S4 自动 `reduce_only` 减仓**。突发行情反向冲击只产生：

- `SHOCK_OBSERVED` 观测事件；
- 保护完整性复核；
- 管理页和告警提示；
- 新增风险 fail-closed。

它不撤旧保护、不改变止损、不提交市价减仓、不尝试部分平仓。当前系统没有可审计的持仓分片与“只能减本次新增仓位”证明链，不能由新 guardian 临时扩大减仓权限。

未来若要做冲击减仓，必须另立方案，实现入场分片、数量归属、部分平仓状态机和 Testnet 故障验证；不能把它隐藏在本方案中。

## 2. v4 仅保留三阶段利润地板

### S0：成本未覆盖

MFE 未达到成本覆盖线时保持初始保护 S0。成本覆盖线使用剩余仓位的手续费、预计平仓手续费、已发生资金费支出和滑点预算；成本不完整则只记录 `COST_UNKNOWN`，不声称净保本。

### S1：降低潜在亏损

触发：`MFE >= max(0.60R0, cost_distance / D0)`。

候选保护收益价：允许最大毛损 `-0.25R0`，即：

- 多头：`E - 0.25 × D0`；
- 空头：`E + 0.25 × D0`。

候选必须经过 Gate price tick、price_type、最新标记/指数/盘口几何、点差和触发方向检查。价格已穿越候选位置时跳过，不追溯补发。

### S2：净保本

触发：`MFE >= 1.00R0` 且当前价格仍位于净保本价的有利一侧。

剩余仓位成本的价差定义为：

`cost_distance = C_remaining / (abs(q_remaining) × contract_multiplier)`。

多头候选价为 `E + cost_distance`，空头候选价为 `E - cost_distance`。如果成本或剩余数量不能确认，不触发 S2。

### S3：峰值锁盈

触发：`MFE >= 1.50R0`。

候选收益价为 `max(cost_distance, 0.50 × MFE × D0)`（多头加到 E，空头从 E 减去）；候选只允许收紧，不允许放宽。S1/S2/S3 的阶段和已确认止损单调保存，移损后仍使用 R0，不用当前止损重算风险。

## 3. 实现分阶段，禁止跨阶段上线

### C1a：纯计算与持久化

- 固化单一完整风险段的 E、S0、D0、q0、q_remaining、MFE、阶段和成本字段。
- 只接管已完成成交、无加仓、无部分成交歧义、原生 TP/SL 完整覆盖且能唯一匹配的持仓。
- 对加仓、外部数量变化、双向歧义、来源不明保护单只记录 `UNMANAGED`，不自动修改。
- 完成多空对称、部分减仓、成本分母、价格步长和重启恢复纯函数测试。

### C1b：保护状态机与准入门

- guardian 独立于 AI 任务，每 10 秒采样；模型超时不影响现有保护。
- 所有扩大风险写路径在 Gate 共用写锁内检查最近 guard heartbeat、环境/账户、策略哈希、持仓修订、未完成保护意图和状态时间。
- guardian 只生成保护候选和 observe 事件；尚未验证 Gate 原位修改/撤建恢复前不发送保护写请求。
- C1b 先运行 7 个完整自然日 observe，验证采样间隔、状态恢复、跳过原因和零交易所写请求。

### C1c：隔离 Testnet 执行验证

- 先确认 Gate 当前账户模式原位修改是否可用；若不可确认，保留撤旧建新实现但不得启用 enforce。
- 覆盖正常修改、旧单撤销不明、新单提交超时但已成功、已触发、恢复失败、进程重启、模型等待、并发锁、部分成交和保护缺口。
- 所有不明结果按 client_id/order_id/已结束订单/触发成交/持仓顺序对账，禁止换 ID 重试。

## 4. 研究对照与上线门槛

固定对照 C0（当前逻辑）、C1（仅工程修复）、C2（C1 + S1～S3）。本 v4 不研究自动冲击减仓。

同时报告扣费净收益、最大回撤、MFE≥0.6R 后转亏率、MFE≥1R 后完整止损率、浮盈保留率、大盈利截断率、保护空窗、失败/重复写和未管理敞口。历史 K 线没有逐笔顺序时报告保守/乐观边界，不把极值当成成交。

策略门最低要求：至少 30 个独立持仓周期、4 个周窗口的未调参验证；C2 扣费后收益为正，相对 C1 收益差区间下界大于零，最大回撤不高于 C1，双倍费用/滑点压力下不转为负期望。任意工程门、执行门或策略门未通过，只能保持 observe。
